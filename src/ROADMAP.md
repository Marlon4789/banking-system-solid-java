# 🗺️ Roadmap del Proyecto

Este proyecto crece poco a poco mientras aprendemos **Java, POO, Interfaces y algo básico de patrones de diseño** juntos.

⚠️ No necesitas saber todo para participar.
La idea es **aprender paso a paso**, sin presión.

Este roadmap puede cambiar con nuevas ideas de la comunidad, si tienes algo en mente no dudes en dejarla saber 😊

---

## ✅ Nivel 1 — Primeros pasos (Actualmente)

Aquí aprendemos lo básico:

* Crear una clase (`Account`)
* Crear servicios
* Transferir dinero entre cuentas
* Usar interfaces
* Separar responsabilidades
* Enviar notificaciones

👉 Objetivo: entender **POO + Interfaces**

---

## 🌱 Nivel 2 — Mejorando el código

Cuando ya entendamos lo básico podemos intentar:

* Validar datos correctamente
* Manejar errores simples
* Mejorar nombres y organización
* Agregar nuevas funcionalidades pequeñas

Ejemplos:

* evitar saldos negativos
* mensajes de error claros

👉 Objetivo: escribir código más limpio

---

## 🧩 Nivel 3 — Guardar información

Ahora empezamos a simular aplicaciones reales:

* Guardar cuentas en memoria mejor organizada
* Crear historial de transferencias
* Separar aún más la lógica

(No necesitas saber bases de datos todavía)

**Se puede usar ArrayList como base de datos**

👉 Objetivo: entender cómo las apps guardan datos

---

## 🚀 Nivel 4 — Pequeños retos opcionales

Para quienes quieran explorar más:

* Crear nuevos tipos de notificación
* Agregar menú por consola
* Mostrar reportes simples
* Practicar refactorización

👉 Objetivo: ganar confianza programando

---

## ⭐ Nivel 5 — Exploración futura (Opcional)

Si las cosas pintan bien, se puede intentar:

* Conectar una base de datos
* Crear una API
* Aprender testing básico

⚠️ Esto NO es obligatorio.

---

## ❤️ Lo más importante

Este repositorio existe para:

✅ practicar
✅ equivocarse
✅ preguntar
✅ mejorar juntos

No importa tu nivel.
Todos estamos aprendiendo.
