# 🤝 Guía de Contribución

¡Gracias por querer contribuir al Mini Bank System! 🚀

Este proyecto busca ayudar a personas que están aprendiendo Java a colaborar en un entorno similar a proyectos reales.

---

## 📌 Reglas generales

Antes de contribuir:

✅ Lee el README.md

✅ Revisa el ROADMAP.md

✅ Mantén el código simple y educativo

✅ Piensa en el aprendizaje colectivo

---

## 🛠️ Flujo para contribuir

---

### 1️⃣ Haz Fork del repositorio

En la parte superior del repositorio presiona:

👉 **Fork**

Esto creará una copia del proyecto en tu cuenta de GitHub.

---

### 2️⃣ Clona tu Fork

```bash
git clone https://github.com/TU-USUARIO/banking-system-solid-java.git
cd banking-system-solid-java
```

Reemplaza `TU-USUARIO` por tu usuario de GitHub.

---

### 3️⃣ Crear una nueva rama

Nunca trabajes directamente sobre `main/master`.

Ejemplo de rama:

```bash
git checkout -b feature/my-new-functionality
```

Ejemplos recomendados:

* feature/add-notification
* feature/transaction-history
* refactor/account-service
* fix/balance-validation
* docs/update-readme

---

### 4️⃣ Realiza tus cambios

Puedes contribuir con:

* Nuevas funcionalidades
* Refactorización
* Mejoras de código
* Documentación
* Corrección de errores

Mantén el código:

✔ limpio
✔ entendible
✔ educativo

---

### 5️⃣ Guardar cambios

```bash
git add .
git commit -m "feat: add new functionality"
```

---

## 📝 Convención de commits

Usa mensajes claros en inglés.

Tipos recomendados:

* feat → nueva funcionalidad
* fix → corrección de errores
* refactor → mejora interna
* docs → documentación
* test → pruebas

Ejemplos:

```bash
git commit -m "feat: add transfer validation"
git commit -m "fix: prevent negative balance"
git commit -m "docs: update contributing guide"
```

---

### 6️⃣ Subir cambios

```bash
git push origin feature/my-new-functionality
```

---

### 7️⃣ Crear Pull Request

Desde GitHub abre un Pull Request hacia el repositorio original.

Explica:

* Qué hiciste
* Por qué lo hiciste
* Qué mejora aporta

---

## ✅ Buenas prácticas

✔ No romper funcionalidades existentes

✔ Explicar cambios grandes

✔ Código fácil de entender

✔ Respetar a otros colaboradores

---

## ❤️ Filosofía

Este proyecto existe para aprender juntos.

No tengas miedo de contribuir.

Todos estamos aprendiendo.
